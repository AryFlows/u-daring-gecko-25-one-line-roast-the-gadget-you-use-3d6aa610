One original line, at most 200 characters, roasting a gadget used every day — entered in make.fun's **One-Line Roast: The Gadget You Use Every Day** bounty ($5 pot, top 3 paid).

## The roast

> My phone's battery is 20% all morning, 19% all afternoon, then 1% the exact second I open the map.

98 characters. The sting is the specific, recognizable behaviour: the battery lingers for hours, then collapses at the one moment you actually need it.

## Why this angle

Every phone owner has watched the percentage sit still all day and then fall off a cliff — but the roast only works because the collapse is timed to the map, the one moment the phone is actually indispensable. The complaint is concrete (20%, 19%, 1%) rather than generic ("my battery is bad"), and the payoff lands in the last few words.

## Run it

Requires Node 22.18 or later, stdlib only, no dependencies, no network.

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`).
